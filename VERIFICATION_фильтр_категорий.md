## Технические детали реализации

### Логика работы чекбоксов:
- При выборе категории: выбирается эта категория и все её дочерние (рекурсивно)
- При снятии выбора с категории: снимается выбор с этой категории и всех её дочерних (рекурсивно)
- Состояние чекбоксов обновляется на основе состояния дочерних элементов:
  - Все дочерние выбраны → чекбокс отмечен
  - Ни один дочерний не выбран → чекбокс снят
  - Некоторые дочерние выбраны → чекбокс в неопределенном состоянии

### Фильтрация товаров:
- При отправке запроса к бекенду используется параметр `category_ids` со списком всех выбранных ID категорий
- На бекенде фильтрация происходит через SQL-запрос: `Product.category_id.in_(selected_category_ids)`
- Это обеспечивает эффективную фильтрацию на уровне базы данных

### Сохранение состояния:
- Состояние фильтров сохраняется в localStorage по ключу `categoryFilter_selectedIds`
- При загрузке страницы состояние восстанавливается из localStorage
- Это обеспечивает сохранность выбора категорий между сессиями

## Как проверить работу:

1. Запустите сервер: `python -m uvicorn src.server.main:app --host 0.0.0.0 --port 8000 --reload`
2. Откройте страницу товаров: http://localhost:8000/products
3. Нажмите на кнопку с надписью "Все категории" в разделе фильтров
4. Выберите несколько категорий в открывшемся дереве
5. Обратите внимание, что:
   - При выборе родительской категории автоматически выбираются все дочерние
   - При выборе некоторых дочерних категорий родительская показывает неопределенное состояние
   - Количество выбранных категорий отображается корректно (только дочерние)
   - При закрытии и повторном открытии dropdown состояние сохраняется
   - Товары фильтруются только по выбранным категориям
   - Состояние сохраняется при перезагрузке страницы
