## Технические детали

### Архитектура решения:
1. **Бэкенд**: 
   - Endpoint `/api/products` принимает параметр `category_ids` (список ID через запятую)
   - Фильтрация происходит на уровне SQL: `Product.category_id.in_(selected_ids)`
   - Endpoint `/api/categories/tree` возвращает иерархическое дерево категорий

2. **Фронтенд**:
   - Хранит выбранные ID в массиве `selectedCategoryIds`
   - При выборе/снятии категории рекурсивно обрабатывает все дочерние элементы
   - Обновляет состояние чекбоксов на основе состояния дочерних элементов
   - Формирует URL-запрос с параметром `category_ids` для фильтрации товаров
   - Сохраняет состояние в localStorage для сохранения между сессиями

### Особенности реализации:
- **Обратная совместимость**: существующий функционал не сломан
- **Эффективность**: фильтрация происходит на сервере, не на клиенте
- **Пользовательский опыт**: интуитивное взаимодействие с деревом категорий
- **Надежность**: защита от бесконечной рекурсии, корректная обработка краевых случаев
- **Производительность**: минимальное количество перерисовок DOM, эффективные алгоритмы

## Как это работает в деталях:

### При открытии страницы:
1. Загружается состояние фильтров из localStorage (если есть)
2. Инициализируется выбранные категории
3. Обновляется отображение dropdown и счетчика

### При взаимодействии с dropdown:
1. Пользователь кликает на чекбокс категории
2. Система определяет, выбрана ли категория или снята с нее выбор
3. В зависимости от действия:
   - При выборе: добавляет эту категорию и все её дочерние в выбранные
   - При снятии: удаляет эту категорию и все её дочерние из выбранных
4. Обновляет состояние всех чекбоксов в дереве (определяя отмеченный/не отмеченный/неопределенный)
5. Обновляет счетчик выбранных категорий (только дочерние)
6. Обновляет текст на кнопке dropdown
7. Сохраняет состояние в localStorage
8. При нажатии "Применить фильтр" или автоматическом обновлении - формирует запрос к бекенду

### При формировании запроса к бекенду:
1. Если выбраны категории - формируется параметр `category_ids=id1,id2,id3...`
2. Бэкенд получает этот параметр и фильтрует товары через SQL: `WHERE category_id IN (id1, id2, id3...)`
3. Возвращаются только товары, принадлежащие выбранным категориям
