# План: Исправление отображения товаров при выборе категорий

## Проблема
Список товаров не отображается при выборе категорий в dropdown.

## Причина
При закрытии dropdown (клик вне списка) не вызывается функция `loadProducts()` для загрузки товаров с учетом выбранных категорий.

## План решения

### 1. Модифицировать обработчик закрытия dropdown
Добавить вызов `loadProducts()` при закрытии dropdown (клик вне списка категорий).

**Файл**: `src/server/templates/products.html`
**Строки**: ~370-376

**Изменение**:
```javascript
// Закрытие dropdown при клике вне его
document.addEventListener('click', function(event) {
    const dropdown = document.getElementById('categoryDropdown');
    const button = document.getElementById('categoryDropdownButton');
    if (dropdown && button && !dropdown.contains(event.target) && !button.contains(event.target)) {
        dropdown.style.display = 'none';
        // Загружаем товары после закрытия dropdown
        loadProducts();
    }
});
```

### 2. Добавить вызов loadProducts() при изменении чекбоксов
При выборе/снятии категории в dropdown автоматически загружать товары.

**Файл**: `src/server/templates/products.html`
**Функция**: `toggleCategoryCheckbox`

### 3. Оптимизация: не отображать категории без товаров (опционально)
После загрузки товаров, получить список category_id с товарами и обновить отображение категорий, скрыв те, которые не имеют товаров.

### 4. Показывать количество товаров в каждой категории (опционально)
После загрузки товаров обновить количество товаров в каждой категории в дереве.

## Реализованные изменения

### Изменение 1: Закрытие dropdown с загрузкой товаров
При клике вне dropdown автоматически загружать товары.

### Изменение 2: Debounce для предотвращения частых запросов
Добавить небольшую задержку перед загрузкой товаров при быстром изменении выбора категорий.

## Критерии приемки

1. ✅ При выборе категории в dropdown автоматически загружаются товары
2. ✅ При закрытии dropdown (клик вне списка) автоматически загружаются товары
3. ✅ Список товаров отображается только для выбранных категорий
4. ✅ При пустом результате показывается соответствующее сообщение
5. ✅ Интерфейс не "дергается" при частых изменениях выбора категорий
